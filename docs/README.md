## How to use this documentation

- Use each phase file as a learning log and implementation record.
- Notes in each file explain what was built, why it was built, what issues appeared, and how they were solved.
- These docs are intended for future reference during project growth and system design study.

## Suggested workflow

1. Complete one phase of the project.
2. Add a new markdown file under the docs folder.
3. Update this index file with the new phase details.
4. Record:
   - Topic title
   - What was covered
   - Activities done
   - Problems faced and fixes
   - Commands used
   - Learning outcomes
